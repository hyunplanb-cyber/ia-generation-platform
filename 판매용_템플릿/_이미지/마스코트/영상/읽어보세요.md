# 마스코트 «움직이는» 영상 — 여기에 넣으세요

SNS 영상 우측 상단에 얹히는 마스코트 영상입니다.
여기 mp4 를 넣어 두면 `영상굽기.mjs` 가 **편마다 하나를 골라** 그 편 내내 씁니다.

## 넣을 때 지킬 것

| | |
| --- | --- |
| **길이** | 8~12초. 짧으면 반복이 잦아 보이고, 길면 한 편에 다 안 나온다 |
| **배경** | 둘 다 된다. 흰 배경이면 상단 흰 띠(#FEFEFE)에 녹아 떠 있는 것처럼 보이고, 장면 배경이면 네모난 «창»처럼 보인다 |
| **여백** | 마스코트가 화면 가장자리에 닿지 않게. 닿으면 잘려 보인다 |
| **이름** | 무엇을 하는 장면인지 한국어로. `사무실_컴퓨터.mp4` 처럼 |

## ⛔ 잘리는 사고를 막는 규칙

2026-08-19 에 커피 테이블을 빼려고 왼쪽을 잘랐다가 **빈백까지 29px 잘라먹었다.**
소품을 빼고 싶으면 «잘라내지» 말고 **처음부터 소품 없이 찍는다.**
굽는 쪽은 자르지 않고 통째로 얹는다 — 높이만 맞춘다.
