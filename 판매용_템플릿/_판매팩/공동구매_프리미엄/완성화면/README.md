# 공동구매(공구) 플랫폼 — 완성 화면 (프리미엄)

`_판매팩/공동구매_프리미엄/` 의 파일 세 개를 그대로 읽어 만든 정적 사이트입니다.

| 넣은 파일 | 무엇을 정했나 |
|---|---|
| `07_AI빌드_스펙팩.json` | 화면 125개의 구성·기능·화면 이동 |
| `디자인프리셋/가이드_02_미니멀모노.json` | 색 · 글꼴 · 모서리 · 간격 · 컴포넌트 규칙 |
| `디자인프리셋/레이아웃_A_타이포강조형.json` | 화면 뼈대 (어두운 큰 히어로 · 계단식 카드 · 한 줄 GNB · 하단 고정 바) |

빌드 도구·프레임워크·외부 CDN 없이 HTML·CSS·바닐라 JS만 씁니다.

## 바로 보기

- 전체 화면 목록: `index.html` (더블클릭)
- 참여자 홈: `pages/HO0101.html` · 공구 상세: `pages/DE0101.html` · 진행자 화면: `pages/HM0101.html`
- 로컬 서버로 보기(권장):

```bash
node build/serve.mjs
```

→ http://localhost:4173 (포트를 바꾸려면 `PORT=4176 node build/serve.mjs`)

## 영역이 둘입니다

참여자가 쓰는 메뉴(홈·공구 목록·마감 임박·내 공구함·관심·알림)와 진행자가 쓰는
메뉴(진행자 대시보드·공구 개설·발주·배송·정산)는 **헤더를 따로 씁니다.**

한 계정이 두 권한을 가지며, 오가는 길은 우측 상단 하나뿐입니다 —
참여자 화면에서는 `진행자 화면으로`, 진행자 화면에서는 `참여자 화면 보기`.

## 이 서비스의 주인공

달성률 게이지와 마감 카운트다운입니다. 부품으로 따로 빼서 어느 화면에서나
같은 모양으로 나옵니다.

- **달성률 게이지** — 목표 대비 몇 %인지. 100%를 넘으면 초록, 불발이면 회색이 됩니다.
- **마감 카운트다운** — 3시간 안쪽이면 빨갛게 바뀝니다. 큰 타이머는 초 단위로 실제로 줄어듭니다.
- **단계별 가격표** — 인원 구간마다 값이 다르고, 지금 어느 단계인지 표시됩니다.

## 미니멀 모노를 어떻게 지켰나

가이드 02의 두 규칙이 이 사이트 전체를 지배합니다.

- **그림자를 쓰지 않습니다.** 깊이는 1px 테두리와 배경 대비로만 냅니다. 카드·표·사이드바 전부.
- **색을 쓰지 않습니다.** 검정(#111)·흰색·종이색(#F0EFEB)뿐입니다. 색이 남아 있는 곳은 **상태**뿐 —
  성사는 초록(#1A7F37), 마감 임박·오류는 빨강(#CF222E), 주의는 갈색(#9A6700).
- 강조는 색이 아니라 **반전**으로 냅니다. 할인율 배지는 검정 바탕에 흰 글자, 나머지 배지는 테두리만.
- 배지 11px·모서리 4px, 카드·버튼·입력 모서리 6px, 표 헤더는 배경 없이 아래 2px 선,
  사이드바 활성 항목은 좌측 2px 검정 바. 글자 굵기는 600을 넘지 않습니다.
- 예외가 하나 있습니다 — **카카오·네이버 로그인 버튼**은 브랜드 색을 그대로 씁니다(AC0101).
  남의 브랜드 표시라 회색으로 바꾸면 무슨 버튼인지 알아보기 어렵습니다.

## 레이아웃 A를 어떻게 지켰나

- **히어로** — 어두운 배경에 화면 폭을 채운 큰 제목(최대 64px), 바로 아래 숫자 지표 4개를 세로선으로 나눠 한 줄로.
- **목록** — 카드를 나란히 두지 않고 위아래로 어긋나게(계단) 놓고, 카드마다 순위 숫자를 하나씩 얹습니다.
- **내비게이션** — 어두운 한 줄 GNB, 오른쪽 끝에 밝은 버튼 하나.
- **상세** — 상단 갤러리·어두운 띠에 제목과 핵심 숫자, 아래는 밝은 본문, 액션은 하단 고정 바.

## 공통으로 지킨 것

- **뒤로가기** — 메뉴의 첫 화면을 뺀 115개 화면 좌측 상단에 `‹ 상위 화면`과 현재 위치를 둡니다.
  목적지는 스펙팩이 화면마다 정해 둔 값 그대로입니다.
- **상태 띠** — 3뎁스 화면은 상단에 `상태 | 지금 무엇이 다른가`를 한 줄로 알려 줍니다.
- **화면 목록** — 모든 화면 우하단에 `☰ 화면 목록` 버튼이 있어 언제든 전체 목록으로 돌아갑니다.
- **누를 수 있게 보이는 것은 전부 눌립니다** — 버튼 989개가 모두 반응합니다. 탭·필터·수량·토글처럼
  화면 안에서 끝나는 조작은 실제로 동작하고, 서버가 필요한 것(결제·발송·정산)만 짧은 안내로 대신합니다.
- **화면 링크 3,361개가 모두 이어집니다** — 눌러서 아무 데도 못 가는 링크가 없습니다.
- **모바일에서도 가로로 넘치지 않습니다** — 375px에서 125개 화면 전부 확인했습니다.
- **사진 자리** — 실제 사진 대신 무엇이 들어갈 자리인지와 권장 크기를 적은 옅은 블록으로 두고,
  적어 둔 비율(상품 1:1, 상세 이미지 5:7, 배너 8:3)을 그대로 지킵니다.

## 다시 만들기

스펙팩이나 색을 고친 뒤 다시 굽습니다.

```bash
node build/generate.mjs
```

검사(끊긴 링크·반응 없는 버튼·빈 화면)는 이렇게 돌립니다.

```bash
node build/check.mjs
```

- `build/data.mjs` — 화면에 채워 넣는 표본 내용(공구·참여·정산)
- `build/ui.mjs` — 공통 부품(게이지·카운트다운·단계별 가격표·카드·표·토스트·모달)과 페이지 껍데기
- `build/pages-*.mjs` — 화면별 내용. 부모 화면 하나가 `v` 값에 따라 상태 화면들을 함께 만듭니다
- `assets/css/base.css` — 색·글꼴·간격. 프리셋을 바꾸려면 위쪽 `:root` 를 고치면 됩니다
