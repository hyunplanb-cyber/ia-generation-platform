# 뷰티샵 예약 플랫폼 — 완성 화면 (디럭스)

`_판매팩/뷰티샵_디럭스/` 의 파일 세 개를 그대로 읽어 만든 정적 사이트입니다.

| 넣은 파일 | 무엇을 정했나 |
|---|---|
| `07_AI빌드_스펙팩.json` | 화면 49개의 구성·기능·화면 이동 |
| `스펙팩/가이드_03_일렉트릭바이올렛.json` | 색 · 글꼴 · 모서리 · 간격 · 컴포넌트 규칙 |
| `스펙팩/레이아웃_B_목록중심형.json` | 화면 뼈대 (목록 · 내비 · 상세) |

빌드 도구·프레임워크·외부 CDN 없이 HTML·CSS·바닐라 JS만 씁니다.

## 프리미엄과 무엇이 다른가

같은 설계를 **다른 프리셋**으로 만들면 얼마나 다른 얼굴이 되는지 나란히 보시라고
두 등급의 프리셋을 다르게 두었습니다.

| | 디럭스 | 프리미엄 |
|---|---|---|
| 설계 깊이 | 2뎁스 (메뉴 → 화면) | 3뎁스 (메뉴 → 화면 → 탭·상태) |
| 화면 수 | 49개 | 136개 |
| 가이드 프리셋 | 03 일렉트릭 바이올렛 (보라 `#5B4FE5`) | 01 코럴 선셋 (주황 `#F0654F`) |
| 레이아웃 프리셋 | B 목록 중심형 | A 사진 중심형 |

## 바로 보기

- 전체 화면 목록: `index.html` (더블클릭)
- 고객 홈: `pages/HO-01.html` · 매장 홈: `pages/PT-01.html`
- 로컬 서버로 보기(권장):

```bash
node build/serve.mjs
```

→ http://localhost:4173 (포트를 바꾸려면 `PORT=4175 node build/serve.mjs`)

손님이 쓰는 메뉴(홈·매장 탐색·예약하기·내 예약·리뷰·내 정보)와 매장이 쓰는
메뉴(매장 홈·예약 관리·매장 운영·정산)는 **헤더를 따로 씁니다.** 한 계정이 두
권한을 가지며, 손님 화면 우측 상단의 `예약 관리 화면으로` 하나로만 넘어갑니다.
권한이 없으면 입점 신청으로 보냅니다.

## 공통으로 지킨 것

- **뒤로가기** — 메뉴의 첫 화면을 뺀 38개 화면 좌측 상단에 `‹ 상위 화면`과 현재
  위치를 둡니다. 목적지는 스펙팩이 화면마다 정해 둔 값 그대로입니다.
- **화면 목록** — 모든 화면 우하단에 `☰ 화면 목록` 버튼이 있어 언제든 전체
  목록으로 돌아갑니다.
- **누를 수 있게 보이는 것은 전부 눌립니다** — 탭·필터·달력·수량처럼 화면 안에서
  끝나는 조작은 실제로 동작하고, 서버가 필요한 것(저장·삭제·발송)만 짧은 안내로
  대신합니다. 버튼 586개 전부 반응합니다.
- **사진 자리** — 「예시 이미지」 표시를 박은 견본 사진 35장을 192곳에 깔아 두었습니다
  (`assets/예시/`). **그대로 쓰시라고 넣은 것이 아닙니다.** 여기에 어떤 사진이
  들어가는 자리인지 눈으로 보시라고 넣은 것이니 가진 사진으로 바꿔 넣으세요.
  자리마다 적어 둔 비율은 그대로 지킵니다.

## 사진 바꾸기

`사진바꾸기.csv` 를 엑셀로 열면 **어느 화면 어느 자리에 어떤 파일이 들어갔는지**
192줄이 다 적혀 있습니다.

| 화면ID | 화면명 | 어떤 자리 | 종류 | 권장 크기 | 지금 들어간 사진 |
|---|---|---|---|---|---|
| HO-01 | 홈 - 비로그인 | 매장 대표 | 매장 | 1200×1200 | 뷰티 - 15.webp |

바꾸는 법은 하나입니다. **`assets/예시/` 안의 파일을 같은 이름으로 덮어쓰세요.**
HTML 을 열 필요가 없고, 그 파일이 쓰인 자리가 한꺼번에 바뀝니다.

- 확장자가 달라도 됩니다(`.jpg` 를 `뷰티 - 15.webp` 라는 이름으로 저장해도 열립니다).
  이름만 같으면 됩니다.
- **비율이 달라도 괜찮습니다.** 자리마다 `object-fit: cover` 가 걸려 있어 가운데를
  기준으로 알아서 잘립니다. 「권장 크기」는 *그 정도 해상도면 안 흐리다*는 뜻이지
  꼭 그 비율로 잘라 오시라는 뜻이 아닙니다.
- 한 파일이 여러 자리에 쓰입니다. 한 자리만 따로 바꾸시려면 그 자리의 `<img>`
  주소를 새 파일 이름으로 고쳐 주세요.

## 다시 만들기

스펙팩이나 색을 고친 뒤 다시 굽습니다.

```bash
node build/generate.mjs
```

> ⚠ 다시 구우면 `pages/*.html` 을 통째로 새로 씁니다. 깔아 둔 예시 사진도 함께
>빠지고 **옅은 회색 자리표로 돌아갑니다.** 어차피 바꿔 넣으실 자리라 문제는
>없지만, 사진이 깔린 화면을 다시 보시려면 다시 굽기 전 상태를 따로 복사해 두세요.
