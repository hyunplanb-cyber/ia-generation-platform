# 공동구매(공구) 플랫폼 — 완성 화면 (디럭스)

`_판매팩/공동구매_디럭스/` 의 파일 세 개를 그대로 읽어 만든 정적 사이트입니다.

| 넣은 파일 | 무엇을 정했나 |
|---|---|
| `07_AI빌드_스펙팩.json` | 화면 37개의 구성·기능·화면 이동 |
| `디자인프리셋/가이드_03_코럴선셋.json` | 색 · 글꼴 · 모서리 · 간격 · 컴포넌트 규칙 |
| `디자인프리셋/레이아웃_B_사진중심형.json` | 화면 뼈대 (사진 모자이크 · 매거진 2열 · 2단 헤더 · 하단 고정 바) |

빌드 도구·프레임워크·외부 CDN 없이 HTML·CSS·바닐라 JS만 씁니다.

## 바로 보기

- 전체 화면 목록: `index.html` (더블클릭)
- 참여자 홈: `pages/HO-01.html` · 진행자 화면: `pages/HM-01.html`
- 로컬 서버로 보기(권장):

```bash
node build/serve.mjs
```

→ http://localhost:4173 (포트를 바꾸려면 `PORT=4175 node build/serve.mjs`)

## 영역이 둘입니다

참여자가 쓰는 메뉴(홈·공구 목록·마감 임박·내 공구함·관심·알림)와 진행자가 쓰는
메뉴(진행자 대시보드·공구 개설·발주·배송·정산)는 **헤더를 따로 씁니다.**

한 계정이 두 권한을 가지며, 오가는 길은 우측 상단 하나뿐입니다 —
참여자 화면에서는 `진행자 화면으로`, 진행자 화면에서는 `참여자 화면 보기`.
아직 진행자가 아니면 전환 대신 **진행자 시작 안내(HS-01)** 로 보냅니다.

## 이 서비스의 주인공

달성률 게이지와 마감 카운트다운입니다. 부품으로 따로 빼서 어느 화면에서나
같은 모양으로 나옵니다.

- **달성률 게이지** — 목표 대비 몇 %인지. 100%를 넘으면 초록, 불발이면 회색이 됩니다.
- **마감 카운트다운** — 3시간 안쪽이면 빨갛게 바뀝니다. 큰 타이머는 초 단위로 실제로 줄어듭니다.
- **단계별 가격표** — 인원 구간마다 값이 다르고, 지금 어느 단계인지 표시됩니다.

## 공통으로 지킨 것

- **뒤로가기** — 메뉴의 첫 화면을 뺀 27개 화면 좌측 상단에 `‹ 상위 화면`과 현재
  위치를 둡니다. 목적지는 스펙팩이 화면마다 정해 둔 값 그대로입니다.
- **화면 목록** — 모든 화면 우하단에 `☰ 화면 목록` 버튼이 있어 언제든 전체
  목록으로 돌아갑니다.
- **누를 수 있게 보이는 것은 전부 눌립니다** — 탭·필터·수량·토글처럼 화면 안에서
  끝나는 조작은 실제로 동작하고, 서버가 필요한 것(결제·발송·정산)만 짧은 안내로
  대신합니다. 버튼 329개 전부 반응합니다.
- **화면 링크 1,262개가 모두 이어집니다** — 눌러서 아무 데도 못 가는 링크가 없습니다.
- **글자가 다 읽힙니다** — 코럴(`#F0654F`)은 흰 배경 위 본문 글자로 쓰면 3.1:1이라
  흐립니다. 글자에는 한 단계 진한 `#B23A26`을 따로 두었습니다. 게이지·배지·테두리는
  원래 코럴 그대로입니다.
- **사진 자리** — 실제 사진 대신 무엇이 들어갈 자리인지와 권장 크기를 적은 옅은
  블록으로 두고, 적어 둔 비율(상품 1:1, 상세 이미지 5:7)을 그대로 지킵니다.

## 다시 만들기

스펙팩이나 색을 고친 뒤 다시 굽습니다.

```bash
node build/generate.mjs
```

- `build/data.mjs` — 화면에 채워 넣는 표본 내용(공구·참여·정산)
- `build/ui.mjs` — 공통 부품(게이지·카운트다운·단계별 가격표·카드·표)과 페이지 껍데기
- `build/pages-*.mjs` — 화면별 내용
- `assets/css/base.css` — 색·글꼴·간격. 프리셋을 바꾸려면 위쪽 `:root` 를 고치면 됩니다
