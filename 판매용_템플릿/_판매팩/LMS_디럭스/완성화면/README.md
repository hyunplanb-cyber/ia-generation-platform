# 온라인 강의 플랫폼(LMS) — 완성 화면 44개

`07_AI빌드_스펙팩.json` 의 화면 정의와 디자인 프리셋 두 벌로 만든 정적 화면 견본입니다.

- 가이드 · **가이드_03_코럴선셋** (색 · 글꼴 · 모서리 · 여백)
- 레이아웃 · **레이아웃_A_대시보드형** (화면 뼈대)

## 열어 보기

`index.html` 을 브라우저로 열면 화면 44개가 목록으로 나옵니다. 눌러서 돌아다녀 보세요.

주소로 열 때는 서버가 하나 필요합니다.

```bash
node build/serve.mjs
```

`http://localhost:5173` 에서 열립니다.

## 폴더

```
index.html            전체 화면 목록
pages/                화면 44개 (HO-01.html … AU-05.html)
assets/css/base.css   디자인 시스템 한 벌
assets/js/app.js      공통 동작 (탭·필터·정렬·펼치기·계산)
assets/fonts/         Paperlogy — 파일을 함께 담아 인터넷 없이도 글꼴이 나옵니다
스펙팩/                이 화면들을 만든 스펙과 프리셋 3개
build/                화면을 찍어내는 생성기
  data.mjs            ★ 강의·수강생·후기 같은 내용
  ui.mjs              공통 부품 (카드·표·배지·차트)
  pages-*.mjs         화면별 구성
  generate.mjs        실행하면 44개 화면을 다시 만듭니다
```

## 내용 고치기

`build/data.mjs` 에서 강의명·가격·수강생 이름 같은 것을 고친 뒤 다시 만들면 됩니다. (Node.js 필요)

```bash
node build/generate.mjs
```

## 화면 뼈대

**쓰는 사람이 다른 메뉴는 사이드바를 나눠 두었습니다.**

| | 왼쪽 사이드바 | 화면 |
| --- | --- | --- |
| 수강생 | 둘러보기 · 학습 · 내 정보 · 계정 | HO · CO · CL · MY · AU |
| 강사 | 강사센터 · 수업 편성 · 학생 관리 · 출결·평가 · 정산 | TC · CU · ST · GR |

오갈 때는 사이드바 맨 아래 진입점 하나로만 이동합니다 (`강사센터 화면으로` ↔ `고객 화면 보기`).
계정 화면(AU)은 헤더 없이 가운데 정렬된 단독 화면입니다.

## 어디까지 동작하나요

**화면 안에서 끝나는 조작은 실제로 값이 바뀝니다.**
탭 전환 · 필터 · 정렬 · 검색 · 펼치기/접기 · 체크 · 토글 · 슬라이더 · 수량 ± ·
파일 올리기 흉내 · 차시 순서 바꾸기 · 금액 계산 · 수료 인원 계산 · 출석 칸 바꾸기가 그렇습니다.

**서버가 있어야 하는 것은 짧은 안내 문구로 대신합니다.**
저장 · 삭제 · 발송 · 결제 · 로그인 · 내려받기가 그렇습니다.

각 화면 우하단의 `화면 정보` 버튼을 누르면 화면ID · 화면명 · 기능정의와 연결 화면을 볼 수 있습니다.
