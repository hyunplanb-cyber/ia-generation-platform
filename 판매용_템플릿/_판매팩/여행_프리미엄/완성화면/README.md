# 여행 프리미엄 — 예약 플랫폼 프로토타입

`07_AI빌드_스펙팩.json`의 **144개 화면**을 `프리셋_01_모던네이비.json` 디자인 시스템으로 구현한 정적 사이트입니다.
빌드 도구·프레임워크·외부 CDN 없이 HTML·CSS·바닐라 JS만 사용합니다.

## 바로 보기

- 전체 화면 목록: `index.html` (더블클릭으로 열면 됩니다)
- 홈 화면: `pages/HO0101.html`
- 로컬 서버로 보기(권장):

```bash
node 여행_프리미엄_사이트/build/serve.mjs
```

→ http://localhost:4173

## 화면 구성

| 메뉴 | 코드 | 화면 수 | 기본 화면 |
|---|---|---|---|
| 홈 | HO | 16 | 홈 / 여행지 홈 / 검색 결과 / 검색 결과 없음 / 테마 기획전 |
| 상품 | PR | 31 | 상품 목록 / 상세 / 날짜·옵션 / 패스 상세 / 비교 / 마감 / 후기 / 찜 |
| 장바구니 | CT | 7 | 장바구니 / 비어 있음 |
| 예약·결제 | BK | 23 | 여행자 정보 / 결제 / 완료 / 실패 / 확정 대기 / 최소 인원 미달 |
| 바우처 | VC | 14 | 목록 / 상세 / 만료 / 재발급 |
| 마이페이지 | MY | 40 | 로그인 / 가입 / 예약 내역·상세 / 취소 / 후기 / 쿠폰 / 여정 / 알림 / 설정 |
| 고객센터 | CS | 13 | FAQ / 1:1 문의 / 문의 내역 / 공지 / 취소·환불 규정 |
| **합계** | | **144** | **43개 기본 + 101개 상태·세부** |

- **기본 화면**(`...01`)은 스펙팩의 화면 프롬프트를 그대로 구현했습니다.
- **상태·세부 화면**(`...02` 이상)은 스펙팩 지침대로 *상위 화면의 레이아웃·컴포넌트·톤을 유지한 채 해당 상태만 바뀐 모습*으로 만들었습니다.
  (예: `CT0104` 선택 삭제 확인 = 장바구니 + 확인 모달, `HO0304` = 검색 결과 + 스켈레톤)
- 상태 화면 상단에는 어떤 상태인지 알려주는 주황색 띠가 있고, 모든 화면 우하단의 **화면 정보** 버튼을 누르면
  pageId · 화면명 · 기능정의 · 연결 화면을 확인할 수 있습니다.

## 디자인 시스템 (프리셋 01 모던 네이비)

`assets/css/base.css`의 `:root`에 프리셋 값을 토큰으로 그대로 넣었습니다.

- 색: primary `#2B4A8B` / hover `#1F3A73` / accent `#FF7A30` / bg `#F5F7FA` / surface `#FFFFFF` / text `#16233F` / muted `#5A6B8C` / border `#DFE4EC` / success `#0F7A52` / warning `#B4761A` / danger `#C0392B`
- 타이포: Pretendard(폴백 Noto Sans KR) · 페이지 제목 32/700, 섹션 22/700, 카드 18/600, 본문 15/400, 보조 13/400, 표 헤더 13/600
- 라운드: 카드 12 / 버튼·입력 8 / 배지 6 · 간격 4px 배수(카드 내부 20, 섹션 32)
- 그림자: `0 1px 3px rgba(22,35,63,.08)` — **카드에만** 적용, 버튼·입력에는 미적용
- 컴포넌트 규칙: 버튼 높이 40, 입력 포커스 시 primary 2px 테두리, 배지는 상태색 10% 배경 + 진한 글자, 표 헤더 배경 채움·행 높이 44, 사이드바 활성 항목만 primary 10% 배경

## 파일 구조

```
여행_프리미엄_사이트/
├─ index.html              전체 화면 목록 + 프리셋 색상표
├─ pages/                  화면 144개 (HO0101.html … CS0503.html)
├─ assets/
│  ├─ css/base.css         디자인 토큰 + 전체 컴포넌트
│  └─ js/app.js            탭·아코디언·칩·찜·토스트·모달·스텝퍼·달력
├─ 스펙팩/                  참고용 원본 스펙팩·프리셋 JSON
└─ build/
   ├─ generate.mjs         스펙팩을 읽어 144개 HTML 생성
   ├─ data.mjs             샘플 데이터(상품·후기·예약·바우처·쿠폰·알림 등)
   ├─ ui.mjs               공통 컴포넌트와 페이지 셸(GNB·푸터)
   ├─ pages-*.mjs          메뉴별 화면 빌더
   ├─ serve.mjs            로컬 미리보기 서버
   └─ qa.html              전체 화면 자동 점검(가로 스크롤·끊어진 링크)
```

## 다시 생성하기

화면 내용을 수정하려면 `build/pages-*.mjs`를 고친 뒤:

```bash
node 여행_프리미엄_사이트/build/generate.mjs
```

`pages/` 아래 144개 파일과 `index.html`이 다시 만들어집니다.
디자인만 바꿀 때는 `assets/css/base.css`만 고치면 되고 재생성이 필요 없습니다.

## 참고 사항

- 반응형: 1024px 이하에서 사이드·2단 레이아웃이 접히고, 720px 이하에서 그리드가 2열(또는 1열)로 바뀝니다. 상품 상세·패스는 하단 고정 예약 바가 항상 보입니다.
- 사진은 실제 이미지 대신 **결정적 그라디언트 블록**으로 넣었습니다(상품·도시별로 항상 같은 색). 실제 사진으로 교체할 때는 `build/ui.mjs`의 `ph()`만 바꾸면 전 화면에 반영됩니다.
- 폼 전송·결제·저장은 동작하지 않고 안내 토스트만 띄웁니다(검토용 프로토타입).
- 데이터는 가상입니다. 회사·연락처·주소·계좌 정보는 모두 예시값입니다.
