레이아웃 프리셋 2벌 — 무엇을 어디에 놓을지

A. 검색 중심형찾는 게 분명한 서비스. 검색창이 첫 화면의 주인공.
첫 화면 위쪽
화면 폭을 꽉 채운 배경 위에 큰 검색바 1개(입력칸 2~3개 + 검색 버튼). 아래에 숫자 지표 3개.
목록 화면
카드 그리드 3~4열. 카드마다 이미지 → 제목 → 보조정보 → 가격 순.
내비게이션
상단 가로 GNB 한 줄. 로고 · 검색 · 메뉴 · 로그인.
상세 화면
본문 왼쪽 + 오른쪽에 따라다니는 요약·액션 카드(sticky).

어울리는 곳: 예약·검색이 시작점인 서비스(숙소·강의·매장 찾기)

B. 목록 중심형훑어보고 비교한다. 한 화면에 많이 담는다.
첫 화면 위쪽
히어로를 두지 않는다. 제목 + 필터 칩 줄로 바로 시작.
목록 화면
좌측 필터 패널 + 우측 가로 리스트 행(썸네일 왼쪽, 정보 오른쪽, 액션 끝).
내비게이션
상단 가로 GNB + 목록 화면에서만 좌측 필터 사이드바.
상세 화면
상단 요약 바 + 탭으로 나눈 본문.

어울리는 곳: 비교해서 고르는 서비스(중개·구인·상품 비교)
