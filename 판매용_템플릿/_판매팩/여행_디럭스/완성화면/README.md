# 여행 디럭스 — 예약 플랫폼 프로토타입

`스펙팩/07_AI빌드_스펙팩.json`의 **43개 화면(2뎁스)** 을 `가이드_03_소프트파스텔.json` 디자인 시스템으로 구현한 정적 사이트입니다.
빌드 도구·프레임워크·외부 CDN 없이 HTML·CSS·바닐라 JS만 사용합니다.

## 바로 보기

- 전체 화면 목록: `index.html` (더블클릭으로 열면 됩니다)
- 홈 화면: `pages/HO0101.html`
- 로컬 서버로 보기(권장):

```bash
node build/serve.mjs
```

→ http://localhost:4173

## 디자인 시스템 (가이드 프리셋 03 소프트 파스텔 · 검색 중심형)

`assets/css/base.css`의 `:root`에 프리셋 값을 토큰으로 그대로 넣었습니다.

- 색: primary `#5B4FE5` / hover `#4A3DD1` / accent `#FFD54A` / bg `#FAFAFA` / surface `#FFFFFF` / text `#1F2024` / muted `#6B6F76` / border `#E7E7EA`
- 타이포: Pretendard(폴백 Paperlogy) · 페이지 제목 36/800, 섹션 24/700, 카드 18/700, 본문 15/500, 보조 14/500
- 라운드: 카드 16 / 버튼·입력 12 / 배지는 알약 · 간격 4px 배수(카드 내부 24, 섹션 40)
- 그림자: `0 2px 8px rgba(31,32,36,.06)` — **카드에만** 적용
- 레이아웃 골격: **검색 중심형** — 히어로에 큰 검색바, 목록은 카드 그리드, 상단 가로 GNB
- 컴포넌트 규칙: 버튼 높이 40, 입력 포커스 시 primary 2px 테두리, 배지는 상태색 10% 배경 + 진한 글자, 표 헤더 배경 채움·행 높이 44, 사이드바 활성 항목만 primary 10% 배경

## 파일 구조

```

├─ index.html              전체 화면 목록 + 프리셋 색상표
├─ pages/                  화면 43개 (HO-01.html … CS-05.html)
├─ assets/
│  ├─ css/base.css         디자인 토큰 + 전체 컴포넌트
│  └─ js/app.js            탭·아코디언·칩·찜·토스트·모달·스텝퍼·달력
├─ 스펙팩/                  참고용 원본 스펙팩·프리셋 JSON
└─ build/
   ├─ generate.mjs         스펙팩을 읽어 43개 HTML 생성
   ├─ data.mjs             샘플 데이터(상품·후기·예약·바우처·쿠폰·알림 등)
   ├─ ui.mjs               공통 컴포넌트와 페이지 셸(GNB·푸터)
   ├─ pages-*.mjs          메뉴별 화면 빌더
   ├─ serve.mjs            로컬 미리보기 서버
   └─ qa.html              전체 화면 자동 점검(가로 스크롤·끊어진 링크)
```

## 다시 생성하기

화면 내용을 수정하려면 `build/pages-*.mjs`를 고친 뒤:

```bash
node build/generate.mjs
```

`pages/` 아래 43개 파일과 `index.html`이 다시 만들어집니다.
디자인만 바꿀 때는 `assets/css/base.css`만 고치면 되고 재생성이 필요 없습니다.

## 참고 사항

- 반응형: 1024px 이하에서 사이드·2단 레이아웃이 접히고, 720px 이하에서 그리드가 2열(또는 1열)로 바뀝니다. 상품 상세·패스는 하단 고정 예약 바가 항상 보입니다.
- 사진은 실제 이미지 대신 **결정적 그라디언트 블록**으로 넣었습니다(상품·도시별로 항상 같은 색). 실제 사진으로 교체할 때는 `build/ui.mjs`의 `ph()`만 바꾸면 전 화면에 반영됩니다.
- 폼 전송·결제·저장은 동작하지 않고 안내 토스트만 띄웁니다(검토용 프로토타입).
- 데이터는 가상입니다. 회사·연락처·주소·계좌 정보는 모두 예시값입니다.
