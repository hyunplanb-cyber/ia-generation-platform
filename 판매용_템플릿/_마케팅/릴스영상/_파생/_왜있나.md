# _파생 — 왜 여기에 파일이 있나

가로(16:9) 판의 영상 칸은 **1384×1080 = 비율 1.2815** 로 고정이다.
녹화본이 그보다 «옆으로 넓으면» 굽는 쪽이 좌우를 잘라야 하고,
`영상굽기.mjs` 의 안전장치가 **내용을 2% 넘게 자르면 멈춘다.**

⛔ 그때 `"당김": true` 로 뚫지 않는다. 대신 여기에
**위아래로 띠를 붙여 비율만 1.28 로 맞춘 판**을 만들어 쓴다 — 내용은 한 픽셀도 안 잃는다.

띠 색은 **`#20261C`** 다. 영상틀의 `--paper`(영상 칸 바탕)와 같은 색이라
세로 판에서도 띠가 «틀의 일부»로 보이고 검은 상자가 생기지 않는다.

```bash
# H = 원본폭 / 1.2815  (짝수로 올림)
ffmpeg -i <원본> -vf "pad=iw:H:0:(H-ih)/2:0x20261C" -c:a copy <낼것>
```

「가로:세로 1.28 로 찍는다」가 지켜지면 이 폴더는 안 늘어난다.
