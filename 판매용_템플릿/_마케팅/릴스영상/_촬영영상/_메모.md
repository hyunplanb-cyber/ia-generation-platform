# 촬영영상 — 분류와 「현의 의도」

여기에 촬영한 영상을 담습니다. `녹화본목록.mjs` 가 이 파일을 읽어
SNS 콘텐츠 루틴에 그대로 넘깁니다.

⚠ **아래 서식을 지켜 주세요.** 기계가 읽습니다 — 「분류」와 「현의 의도」 두 머리글과,
의도를 적을 때 `## 영상 <파일이름>` 줄만 지키면 나머지는 자유롭게 쓰셔도 됩니다.

## 분류

파일 이름 **맨 앞 숫자**가 분류입니다. 기계가 읽는 것은 «이 숫자»뿐입니다.
2026-09-10 저녁부터는 **갈래 폴더**에도 같은 번호가 붙습니다 —
`_촬영영상/2. 완성화면/2. 완성화면_공구_디럭스/` 는 폴더로도 이름으로도 2번입니다.
(⚠ 둘은 «같은 말»이라 어긋나면 안 됩니다. 폴더에만 번호가 있고 파일 이름에 없으면
 분류가 빕니다 — `1. 팩생성/펫유치원.mp4` 처럼 두지 마세요.
 `기타_….mp4` 는 갈래 폴더 없이 뿌리에 그대로 둡니다.)

| 번호 | 이름 | 무엇을 찍은 것인가 |
| --- | --- | --- |
| 1 | 팩생성 | 홈페이지에서 유저가 직접 AI팩을 만들어 보는 과정 |
| 2 | 완성화면 | 스펙팩을 AI 도구에 넣어 완성화면이 만들어지고, 어떻게 작동하는지 |
| 3 | 검수영상 | 만든 팩을 오픈 전에 한 화면씩 눌러 보는 것. 「다 됐다」와 「정말 다 됐다」 사이에 무엇이 있는지 |
| 4 | 비교 | AI 도구에 한 줄 프롬프트를 넣고 사이트를 생성해 보는 것 |
| 기타 | 기타 | 1~4와 다른 뜻으로 찍은 것 |

**3번 검수영상에 꼭 담을 것** — 눌러서 무언가가 «바뀌는» 자리. 안 바뀌면 검수가 아니다.

## ⭐ 갈래 폴더 한 층 + 2번은 «세트 폴더» (2026-09-10 현님이 두 번에 걸쳐 가르셨습니다)

낮에 2번을 «세트 폴더»로 가르셨고, 저녁에 **갈래 폴더를 한 층 더** 두셨습니다.
그래서 지금은 두 층입니다 — 갈래 폴더(1~4), 그리고 2번 안에만 회차 폴더.
아래는 2026-09-10 저녁에 실제로 훑어 본 모습입니다.

```
_촬영영상/
├─ 1. 팩생성/
│     └─ 1. 팩생성_펫유치원.mp4                  ← 1개짜리, 그대로
├─ 2. 완성화면/                                   ← 이 안에만 «회차 폴더»가 한 층 더
│     ├─ 2. 완성화면_인테리어_프리미엄/
│     │     ├─ 화면영역.mp4        완성화면만 찍은 것
│     │     ├─ 클로드영역.mp4      클로드 화면만 찍은 것
│     │     └─ _통짜.mp4           옛 1개짜리(2분할). ⛔ 지우지 마세요
│     └─ 2. 완성화면_LMS_디럭스_1분/ · _공구_디럭스/ · _공구_디럭스_1/ · _매칭_디럭스/
│        _무료샘플_1분/ · _뷰티샵_프리미엄/ · _여행_144개화면/ · _여행_프리미엄/
│              └─ _통짜.mp4        아직 통짜만 있는 회차 (여덟 곳)
├─ 3. 검수영상/
│     └─ 3. 검수영상_LMS.mp4                     ← 1개짜리, 그대로
├─ 4. 비교/
│     └─ 4. 비교_한줄프롬프트 제작_매칭사이트.mp4 · …_우측.mp4
├─ 기타_사이트.앱 내놓는법.mp4                    ← 기타는 갈래 폴더가 없다. 뿌리에 그대로
├─ 기타_키인영상.mp4
└─ _메모.md
```

**세트가 되는 건 2번뿐**이라 1·3·4·기타는 갈래 폴더 «안에» 파일 그대로 둡니다.

| 이름 | 무엇 |
|---|---|
| `화면영역.mp4` | **가로:세로 0.669** 로 찍으면 잘리는 곳이 없습니다 (예 2160×3230) |
| `클로드영역.mp4` | 크기는 아무래도 좋습니다. **길이만 만들 영상의 1.5~2배** |
| `_통짜.mp4` | 옛 1개짜리. **대본이 시각까지 물고 있어** 지우면 옛 편을 다시 못 굽습니다 |

⛔ **`_통짜.mp4` 를 지우지 마세요.** 2분할을 새로 찍어도 옛 편(영상1~24)은 그것으로 구워집니다.
현님 말씀대로 「이분할 영상의 주제만 만드는 건 아니」므로 옛 통짜 사슬은 계속 삽니다.

만드는 법:  `node 마스터만들기.mjs "2. 완성화면_인테리어_프리미엄"`
**갈래 폴더 이름은 안 적습니다** — `마스터만들기.mjs` 가 `_촬영영상` 아래 한 층을 통째로 뒤져
회차 폴더를 스스로 찾습니다. 갈래가 늘어도 이 명령은 안 바뀝니다.
화면영역·클로드영역이 있으면 그 둘로, 없으면 `_통짜.mp4` 를 갈래 재서 씁니다.

- **분류와 다르게 써도: 된다**
- **다른 분류의 영상과 합성해도: 된다**
- 「현의 의도」가 적혀 있으면 **참고한다.** 다만 **적힌 문구를 그대로 쓰지 않는다** —
  「SNS AI 정보전달 인플루언서」로서 **각색해서** 쓴다.
- 의도가 **안 적힌 영상이라도** 「SNS AI 정보전달 인플루언서」로서 스스로 기획해서 만든다.

# 현의 의도

여기에 영상별로 적습니다. `## 영상 <파일이름>` 로 시작하면 그 아래가 그 영상의 의도입니다.

## 영상 4. 비교_한줄프롬프트 제작_매칭사이트

클로드코드 오퍼스로 매칭 사이트를 제작했다.
프롬프트는 「숨고 같은 매칭 서비스를 만들고 싶어. 견적을 내고, 소통해서 일정 잡는 사이트를 만들어줘」
라고만 적었다.

그럴싸한 사이트는 나왔지만 **고수 화면이 만들어지지 않았고**,
사이트를 만든 뒤에야 「리뷰 기능을 추가할 건지」 물어봤다.

우리는 화면의 흐름을 파악하고 화면목록을 작성한 다음 AI 스펙팩이 제작되므로,
**고수센터 화면과 리뷰 기능까지 모두 생성됨**을 확인할 수 있었다.

- 비교: `2. 완성화면_매칭_디럭스`

## 영상 4. 비교_한줄프롬프트 제작_매칭사이트_우측

위 녹화본에서 **오른쪽 브라우저만** 잘라 낸 것이다 (2026-09-02). 시각은 원본과 같다 —
원본 22초는 이것도 22초다. 자를 때 만든 것: `crop=1854:1438:1040:0`

**왜 따로 만들었나.** 원본은 좌우분할(왼쪽 35.9% 터미널)이라 폭이 2894×2160 = **1.3398** 이다.
가로판(16:9) 구멍은 1.2815 라, 그 녹화본을 그대로 쓰면 굽는 쪽이 **좌우를 2% 깎는다** —
`영상굽기.mjs` 의 잘림 막이에 걸린다. 면제하는 값(`"당김": true`)은 `자막검사.mts` 가
**한 편에 한 곳**만 허용하므로 세 칸에 못 쓴다.

그래서 «비율을 맞춘 녹화본»을 만들었다. 1854×1438 = **1.2893** 으로,
`1. 팩생성_펫유치원`(1.2889)과 사실상 같다. 그래서 한 편에서 둘을 섞어도
세로 칸이 그대로 1080×838 이고 다른 칸이 안 깎인다.

⭐ 쓰는 뜻 — **AI가 기본으로 내놓는 색**(네이비 바탕 + 형광 민트)이 화면을 꽉 채운다.
   `대본_색이달라지는거` 의 앞 세 칸이 이걸 쓴다. 바로 다음 칸에서 우리 프리셋(주황)으로
   넘어가면서 «색이 정해져 있다»는 말이 그림으로 보인다.

⚠ 다른 좌우분할 녹화본도 같은 일을 겪는다. 폭이 1.2815 보다 넓으면 가로판이 깎는다.
  그때는 이렇게 «쓸 쪽만 잘라 비율을 맞춘 녹화본»을 만드는 것이 답이다.

| --- | --- | --- |
| **커버 문구·그림** | ✅ **바꿀 수 있다** | 커버는 `썸네일틀.html` 로 따로 굽고 «이미 구운 본편» 앞에 이어 붙일 뿐이다 |

| 자막 | ⛔ 못 바꾼다 | 같은 까닭 |
| 캡션·해시태그 | ✅ 바꿀 수 있다 | 영상 밖의 글이다 |
