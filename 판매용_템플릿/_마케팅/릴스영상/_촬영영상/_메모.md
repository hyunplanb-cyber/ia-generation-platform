# 촬영영상 — 분류와 「현의 의도」

여기에 촬영한 영상을 담습니다. `녹화본목록.mjs` 가 이 파일을 읽어
SNS 콘텐츠 루틴에 그대로 넘깁니다.

⚠ **아래 서식을 지켜 주세요.** 기계가 읽습니다 — 「분류」와 「현의 의도」 두 머리글과,
의도를 적을 때 `## 영상 <파일이름>` 줄만 지키면 나머지는 자유롭게 쓰셔도 됩니다.

---

## 분류

파일 이름 **맨 앞 숫자**가 분류입니다. `2. 완성화면_공구_디럭스.mp4` → 2번.

| 번호 | 이름 | 무엇을 찍은 것인가 |
| --- | --- | --- |
| 1 | 팩생성 | 홈페이지에서 유저가 직접 AI팩을 만들어 보는 과정 |
| 2 | 완성화면 | 스펙팩을 AI 도구에 넣어 완성화면이 만들어지고, 어떻게 작동하는지 |
| 3 | 검수영상 | 만든 팩을 오픈 전에 한 화면씩 눌러 보는 것. 「다 됐다」와 「정말 다 됐다」 사이에 무엇이 있는지 |
| 4 | 비교 | AI 도구에 한 줄 프롬프트를 넣고 사이트를 생성해 보는 것 |
| 기타 | 기타 | 1~4와 다른 뜻으로 찍은 것 |

**3번 검수영상에 꼭 담을 것** — 눌러서 무언가가 «바뀌는» 자리. 안 바뀌면 검수가 아니다.

## 만드는 규칙

- **분류와 다르게 써도: 된다**
- **다른 분류의 영상과 합성해도: 된다**
- 「현의 의도」가 적혀 있으면 **참고한다.** 다만 **적힌 문구를 그대로 쓰지 않는다** —
  「SNS AI 정보전달 인플루언서」로서 **각색해서** 쓴다.
- 의도가 **안 적힌 영상이라도** 「SNS AI 정보전달 인플루언서」로서 스스로 기획해서 만든다.

# 현의 의도

여기에 영상별로 적습니다. `## 영상 <파일이름>` 로 시작하면 그 아래가 그 영상의 의도입니다.
(파일 이름은 확장자를 빼고 적어도 되고, 붙여 적어도 됩니다.)

## 영상 4. 비교_한줄프롬프트 제작_매칭사이트

클로드코드 오퍼스로 매칭 사이트를 제작했다.
프롬프트는 「숨고 같은 매칭 서비스를 만들고 싶어. 견적을 내고, 소통해서 일정 잡는 사이트를 만들어줘」
라고만 적었다.

그럴싸한 사이트는 나왔지만 **고수 화면이 만들어지지 않았고**,
사이트를 만든 뒤에야 「리뷰 기능을 추가할 건지」 물어봤다.

우리는 화면의 흐름을 파악하고 화면목록을 작성한 다음 AI 스펙팩이 제작되므로,
**고수센터 화면과 리뷰 기능까지 모두 생성됨**을 확인할 수 있었다.

- 비교: `2. 완성화면_매칭_디럭스`
