# ⛔ 이 넷은 다시 못 굽는다 — 구운 것을 여기 둔다

원본 녹화본 `14. 펫유치원/펫유치원2.mp4` 가 사라졌다(2026-08-20 확인 · 휴지통에도 없다).
대본 넷이 그것을 가리키고 있어서 **다시 구울 수가 없다.**

그래서 «이미 구워진 것»이 유일본이다. `%TEMP%/cc-vid-w2/` 에 있었는데
거기는 임시 자리라 언젠가 지워진다. 여기로 옮겨 두었다.

| 편 | 대본 | 상태 |
| --- | --- | --- |
| 눌러봤습니다 | `대본_눌러봤습니다.json` | 올림 |
| 다됐다는말 | `대본_다됐다는말.json` | 올림 |
| 예약다섯단계 | `대본_예약다섯단계.json` | 올림 |

## 무엇을 아직 바꿀 수 있나

| 무엇 | 되나 | 왜 |
| --- | --- | --- |
| **커버 문구·그림** | ✅ | 커버는 따로 굽고 «이미 구운 본편» 앞에 이어 붙일 뿐이다 |
| 캡션·해시태그·올릴 때 | ✅ | 영상 밖의 글이다 |
| **상단 띠 문구** | ⛔ | 띠는 본편 «안»에 구워져 있다 |
| 자막 | ⛔ | 같은 까닭 |

커버를 바꾸려면 `인트로설정_<편>.json` 의 `영상` 을 **여기 있는 `_916.mp4`** 로 가리킨 뒤
`node 영상인트로.mjs 인트로설정_<편>.json` 을 돌린다.

## ⚠ 다시는 이러지 않으려면

- 녹화본을 옮기거나 지우기 전에 **대본이 쓰는지 먼저 본다** — `node _작업/녹화본목록.mjs`
- 구운 영상은 `%TEMP%` 에만 두지 않는다. 거기는 지워지는 자리다.
