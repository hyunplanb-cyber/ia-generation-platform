# 자막을 «그 프레임»에 맞추는 법 (2026-08-31)

> 대본에 `ss` 를 적기 전에 이 문서를 읽는다.
> 여기 적힌 것 하나를 몰라서 2026-08-31 회차가 네 편을 **두 번 구웠다.**

---

## ⛔ `ss` 는 «칸이 시작하는 초»다. 자막이 가리키는 화면은 거기 없다

검수 화면도, 사람 눈도 **칸 한가운데**를 본다. 한 칸은 2.9초이므로 가운데는 1.45초 지점이다.
그리고 배속이 걸리면 원본에서 그만큼 «덜» 읽는다.

```
칸 한가운데가 보는 원본 초 =  ss + 1.45 × 배속
한 칸이 원본에서 쓰는 길이 =  2.9 × 배속
```

| 배속 | 가운데 | 한 칸이 쓰는 길이 |
|---|---|---|
| 1.0 | `ss + 1.45` | 2.90초 |
| 0.8 | `ss + 1.16` | 2.32초 |
| 0.7 | `ss + 1.015` | 2.03초 |
| 0.6 | `ss + 0.87` | 1.74초 |
| 0.5 | `ss + 0.725` | 1.45초 |

**보여주고 싶은 화면이 원본 T 초에 있으면 `ss = T − 1.45 × 배속` 이다.**

⚠ 그리고 **`[ss, ss + 2.9×배속]` 이 통째로 그 화면 위에 있어야 한다.**
가운데만 맞으면 앞뒤가 딴 화면으로 넘어가 「툭툭 끊긴다」가 된다.

⭐ **배속을 1보다 낮추면 한 칸이 쓰는 길이가 짧아져 화면이 덜 바뀐다.**
스크롤이 잦은 녹화본일수록 0.6~0.8 이 맞추기 쉽다. 덤으로 화면이 천천히 흘러 읽힌다.

## 순서 — 이대로 한다

**① 쓸 구간의 «지도»부터 만든다.** 초마다 무엇이 떠 있는지 적는다.

```bash
# ⚠ 대본이 가리키는 «그 파일»에서 뽑는다. _파생/ 판을 쓰면 _파생/ 에서 뽑아야 한다.
cd "판매용_템플릿/_마케팅/릴스영상"
OUT="$TEMP/지도"; mkdir -p "$OUT"
for t in 44 45 46 47 48; do
  ffmpeg -v error -ss $t -i "<녹화본>" -frames:v 1 -vf "scale=620:-1" "$OUT/$(printf %03d $t).png" -y
done
# 여러 장을 한 판으로 붙여 놓고 본다 (drawtext 는 쓰지 마라 — 아래 ⚠)
ffmpeg -v error -i "$OUT/044.png" -i "$OUT/045.png" -i "$OUT/046.png" \
  -filter_complex "[0][1][2]hstack=inputs=3" "$OUT/판.png" -y
```

**② 지도를 보고 `ss = T − 1.45×배속` 로 적는다.** 옆 칸에서 베끼지 않는다.

**③ 굽고 나서 «칸마다» 프레임을 뽑아 눈으로 본다.** 이게 마지막 관문이다.

```bash
V="$TEMP/cc-vid-w2"; OUT="$TEMP/확인"; mkdir -p "$OUT"
for i in $(seq 0 22); do
  t=$(node -e "console.log(($i+0.5)*2.9)")
  ffmpeg -v error -i "$V/<이름>_916.mp4" -ss $t -frames:v 1 \
    -vf "crop=1080:940:0:513,scale=480:-1" "$OUT/$(printf %02d $((i+1))).png" -y
done
```
`crop=1080:940:0:513` 은 **화면 칸 + 자막 첫 줄**을 함께 담는다 — 둘을 나란히 봐야 뜻이 선다.
23장을 한 판으로 붙이면 한눈에 어긋난 칸이 보인다.

**④ 어긋난 칸은 «자막을 화면에 맞추는» 쪽도 답이다.** 초를 옮기기 어려운 자리(모달이
잠깐만 떠 있는 곳 등)에서는 그 프레임에 실제로 보이는 것을 자막으로 쓴다.

## ⚠ 걸려 넘어지는 것들

- **`-ss` 를 `-i` 앞에 둔다.** 굽는 쪽(`영상굽기.mjs`)이 그렇게 찾아가므로 확인도 같아야 한다.
  (「-i 뒤에 두라」는 옛 기록은 **구운 영상**에서 뽑을 때 이야기다. 원본을 볼 때는 굽는 쪽과 맞춘다.)
- **`_파생/` 판을 만들면 키프레임이 원본과 달라진다.** 지도도 그 판에서 다시 만든다.
- **`drawtext` 는 못 쓴다** — fontconfig 이 없어 ffmpeg 가 죽는다. 초는 파일 이름으로 센다.
- **`python` 은 안 깔려 있다.** 잔 작업은 `node -` 나 `node -e` 로 한다.
- 스크롤 중인 페이지는 1초 안에도 딴 곳이 보인다. **그런 자리는 초를 쫓지 말고
  «그 페이지 전체에 대해 참인 말»로 자막을 쓴다.**
