# 주간 SNS 굽는 도구

**여기에 두는 까닭** — 1주차에 만든 스크립트를 `%TEMP%` 에 뒀다가 **청소로 사라져서**
2주차에 처음부터 다시 썼다(2026-08-10). 도구는 프로젝트 안에 남긴다.

| 파일 | 무엇을 |
|---|---|
| **`자막검사.mjs`** | ⛔ **굽기 «전»에 통과해야 한다.** 자막 열세 가지를 세어 본다 (2026-08-17) |
| `영상굽기.mjs` | 대본 JSON 을 받아 **세로 9:16 · 가로 16:9 네 편**을 낸다 (음악까지) |
| `썸네일굽기.mjs` | 썸네일을 굽는다. 목록은 파일 안 배열을 고친다 |
| `표지붙이기.mjs` | **세로 영상 맨 앞에 «움직이는 표지» 1.4초를 붙인다** — 쇼츠용, 아래 설명 |
| `대본_2주차.json` | 지난 회차 대본. 새 회차는 이걸 복사해서 고친다 |

## 쓰는 법 — 이 차례를 지킨다

**⛔ 첫 줄이 `자막검사.mjs` 다. 통과하지 못하면 굽지 않는다.**

```bash
node "판매용_템플릿/_마케팅/_작업/자막검사.mjs" "<대본.json>" "<인트로설정.json>"   # ← 먼저
node "판매용_템플릿/_마케팅/_작업/영상굽기.mjs" "판매용_템플릿/_마케팅/_작업/대본_2주차.json"
node "판매용_템플릿/_마케팅/_작업/썸네일굽기.mjs"
node "판매용_템플릿/_마케팅/_작업/표지붙이기.mjs" "<표지설정.json>"     # 세로 두 편에만
```

**표지를 붙인 뒤에 올린다.** 유튜브는 파일을 바꿔 끼울 수 없어서, 빠뜨리면 다시 올려야 하고
옛 영상이 쌓인다. 한 회차에 여덟 개가 쌓인 적이 있다(2026-08-10).

## 왜 «표지»를 따로 붙이나 — 쇼츠는 썸네일을 안 쓴다

세로로 넘기는 쇼츠 피드에서도, 스튜디오의 Shorts 목록에서도
유튜브는 커스텀 썸네일 대신 **영상 속 한 장면**을 보여준다.
`maxres` 까지 확인하며 세 번 다시 붙였지만 그 자리엔 안 나왔다.

**그래서 썸네일 그림을 영상 맨 앞 1.4초로 넣는다.** 유튜브가 무엇을 하든 상관없어진다.

- 고양이는 **위아래 ±14px · 왕복 1.1초**로 살짝 흔든다. 정지 그림은 「멈춘 줄 알았다」가 된다
- 썸네일틀을 `?facehide=1` 로 굽는다 — **자리 계산은 그대로 두고 고양이 «그림만» 뺀다.**
  face 를 아예 빼면 목록 칸 폭이 달라져 썸네일과 다른 그림이 된다
- 고양이 좌표는 `표지붙이기.mjs` 의 `자리` 표에 있다. **썸네일틀 CSS 와 같은 값이니 한쪽만 고치지 않는다**

표지설정.json 한 줄은 이렇게 생겼다:

```jsonc
{ "이름": "영상1", "pose": "커피_마셔야겠다", "pos": "bl",
  "big": "결제가 실패하면|어떻게 되나요", "sub": "바이브코딩으로 만든 사이트에서",
  "ep": "장비 렌탈 사이트 편", "sheet": "02_IA_화면목록.xlsx · 장비렌탈",
  "rows": "BK0201,보증금·결제,ok|BK0401,결제 실패,q",
  "음악": "Small Kind of Brave.mp3",
  "영상": "…/영상1_결제실패_916.mp4", "낼길": "…/표지_영상1_916.mp4" }
```

나온 것은 `%TEMP%/cc-vid-w2` · `%TEMP%/cc-thumb-w2` 에 있다. 드라이브로는 손으로 옮긴다.

## 먼저 준비할 것 — 화면 캡처

영상에 들어갈 화면은 **팩의 완성화면을 직접 찍어** 쓴다(녹화본보다 주제에 맞다).
`%TEMP%/cc-sns-w2/tall/{화면ID}.png` 에 **1440×2600** 으로 있어야 한다.

```bash
# ① 한글 없는 자리로 통째로 복사하고 「화면 정보」 패널을 끈다
cp -r ".../완성화면/." "$TEMP/cc-sns-w2/site/"
printf '\n.dev{display:none!important}\n' >> "$TEMP/cc-sns-w2/site/assets/css/base.css"

# ② 찍는다 (--screenshot 은 반드시 절대 경로)
chrome --headless=new --disable-gpu --hide-scrollbars --force-device-scale-factor=1 \
  --window-size=1440,2600 --screenshot="…/tall/BK0401.png" --virtual-time-budget=3000 \
  "file:///…/site/pages/BK0401.html"
```

폰 폭 그림·「PC와 폰 나란히」 그림은 `ffmpeg` 으로 만들어 같은 폴더에 `ph_*` · `cmp_*` 로 둔다.
그 둘은 **1440×1125**(비율 1.28)로 맞춘다 — 영상 칸 비율과 같아야 안 잘린다.

## 대본 JSON

```jsonc
{
  "이름": "영상1_결제실패",
  "세로제목": "첫 줄에 주제어,|둘째 줄이 후킹?",   // | 가 줄바꿈
  "가로제목": "짧게|세 줄로|나눈다",              // 기둥이 좁다 — 한 줄 7자까지
  "ep": "장비 렌탈 사이트 편",
  "rows": "BK0201,보증금·결제,ok|BK0401,결제 실패,q",  // 기둥 목록. 회차와 맞춘다
  "칸들": [
    { "cap": ["자막 첫 줄", "둘째 줄"], "cat": "cut", "pose": "굳이_",
      "shots": [{ "page": "CT0101", "zoom": 1.4 }] }
  ]
}
```

- 한 칸 = **2.5초**. 25~40초면 **14칸**이 맞다.
- `shots` 는 1개 또는 3개(2.5초를 나눠떨어지게). 2개·7개는 안 된다.
- `cat`: `cut`(모서리에 걸터앉기) · `full`(영상 칸을 통째로 — 이 칸은 `shots: []`)
- `pose` 는 `릴스영상/_모델/고양이/` 의 파일 이름. 한 편에 3~5번, 같은 포즈 두 번 쓰지 않는다.
- 마지막 칸은 늘 고정 CTA. 둘째 줄을 `<span class='cta'>…</span>` 로 감싼다.

## 여기서 밟은 것 (되풀이하지 말 것)

- **앞장(layer=front)은 `--default-background-color=00000000` 없이는 «흰 종이»로 나온다.**
  얹는 순간 틀과 화면을 통째로 덮는다.
- **가로 영상 칸 폭은 1384(짝수).** 1383 을 주면 h264 가 굽다가 멈춘다.
- **`-loop 1 -t 2.5` 는 76프레임을 낸다.** `-frames:v 75` 로 못 박는다.
- **확대는 1.4배까지.** 우리 화면은 한 폭에 다 담기는 크기라 더 당기면 빈 종이가 된다.
  **컷은 «자리»가 아니라 «화면»을 바꿔서 만든다.**
- ⛔⛔ **`zoom` 기본값은 이제 1.0(가로를 안 자름)이다.** 전에는 0.6 이었고, 그 때문에
  2026-08-17 에 네 편이 좌우로 잘린 채 올라갔다 — 넓은 PC 화면 녹화본에서는 60%로 자르면
  글자가 문장 한가운데서 끊긴다. **당겨야 읽히는 컷만 그 컷에 `zoom` 을 적는다.**
- ⛔ **`"당김": true` 로 잘림 검사를 뚫지 마라.** 그건 한 컷을 면제하는 값인데 대본 전체에
  붙여 검사를 통째로 껐다. 지금은 **한 편에 두 곳 넘으면 `영상굽기.mjs` 가 멈춘다.**
- **프레임을 뽑아 볼 땐 `-ss` 를 `-i` 뒤에 둔다.** 앞에 두면 엉뚱한 토막이 나온다.
- **글꼴 경로를 아스키로 바꿔서 굽는다.** 한글 경로에서 헤드리스 크롬은 조용히 아무것도 안 만든다.
