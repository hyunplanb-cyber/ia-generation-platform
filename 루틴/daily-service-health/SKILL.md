### 열쇠가 401 로 거부될 때

**콘솔에서 사람이 해야 하는 일이다. 네가 못 고친다.** 이렇게 알린다:

> API 열쇠가 죽었습니다. 손님이 지금 AI팩을 못 만듭니다.
> console.anthropic.com → API 키 에서 새로 만드시고, **만료는 「없음(Never)」**으로 두세요.
> 그다음 Vercel 프로젝트 `ia-generation-platform` 의 환경변수 `ANTHROPIC_API_KEY` 를
> 바꾸시면 됩니다. (환경변수는 실행할 때 읽으므로 재배포는 없어도 됩니다.)

⛔ **열쇠 값을 직접 만들거나 어디서 가져오려 하지 마라.** 사람이 콘솔에서 한다.
⛔ **Vercel 의 ANTHROPIC_API_KEY 를 지우라고 말하지 마라** — 그게 손님 몫이다. 지우면 서비스가 죽는다.
