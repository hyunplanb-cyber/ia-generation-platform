## 하는 일

### 1단계 — 바뀐 코드가 «무엇을 바꾸는지» 적는다

분배표의 파일을 열어 바뀐 부분을 읽고, **받는 파일 가운데 무엇이 달라지는지** 적는다.

### 2단계 — ⭐ 옆으로 번지는 것을 찾는다 (이 루틴의 핵심)

**변경이 디자인프리셋에 있더라도, 그 때문에 다른 파일도 고쳐야 하는지 본다.**

| 바뀐 곳 | 같이 봐야 하는 것 |
| --- | --- |
| `lib/design-presets.ts` (색·간격·레이아웃) | 디자인프리셋 md·json · **07 스펙팩의 「디자인」 절** · 08 검수시나리오의 디자인 항목 |
| `lib/export/spec-pack.ts` | 07 md·json **둘 다** · 08 검수시나리오(스펙팩을 보고 만든다면) |
| `lib/export/rows.ts` | 01~04 xlsx · 05 FLOW · 06 pptx |
| 화면·메뉴 자료 구조 | **받는 파일 거의 전부** |
| `lib/export/template-verify.ts` | 08 · 08-1 |

⚠ **md 만 고치고 json 을 안 고치는 일이 잦다.** 07 은 둘이 짝이다. 둘 다 확인한다.

⚠ **글이 서로 싸우는지 본다.** 규칙에는 새 방식이 적혔는데 예시는 옛 방식이면
만드는 쪽(AI)은 **예시를 따른다.** 2026-08-19 에 `overflow` 규칙이 그래서
14개 팩 74곳에 옛 방식으로 들어갔다.

### 3단계 — 한 벌 실제로 뽑아 «열어 본다»

읽기만 하지 말고 **실제로 만들어 본다.** 코드가 도는지는 돌려 봐야 안다.

```bash
npx tsc --noEmit                    # 먼저 타입
npx tsx build-template.mts lms      # 2뎁스 한 벌  → _작업/LMS_온라인강의플랫폼/
npx tsx build-template-deep.mts lms # 3뎁스 한 벌  → _작업/LMS_온라인강의플랫폼_상세IA/
```

⚠ 이 둘은 **완성화면을 안 건드린다.** 문서만 만든다. 안전하다.

나온 것을 **열어서 안을 읽는다.**

- `07_AI빌드_스펙팩.md` — 이번 변경이 들어갔는가. **절 번호가 겹치거나 빠지지 않았는가**
- `07_AI빌드_스펙팩.json` — md 와 같은 내용인가
- `01~04 xlsx` — 행이 비지 않았는가, 머리줄이 맞는가
- `디자인프리셋/` — md 와 json 이 같은 값을 말하는가

⭐ **스펙팩 7절(만들고 나서 — 눈으로 보고, 눌러 보고, 고치기)이 그대로 있는지 반드시 본다.**
손님은 이 스펙팩을 AI 에 넣어 제 화면을 만든다.
**7절이 빠지면 손님의 AI 는 만들고 나서 아무것도 안 눌러 본다.**

### 4단계 — ⛔ 판매팩은 «보지 않는다»

판매팩(`판매용_템플릿/_판매팩/`)은 **2·3·4번 몫이다. 열지 마라.**

네가 고친 것이 판매팩에도 들어가야 한다면, 그것은 **3·4번이 잡는다** —
그들이 「새 지시가 기존 판매팩에 반영됐는가」를 보는 루틴이고, 스펙팩도 판매팩의 파일이다.

⛔ 2026-08-19 에 여기가 헷갈렸다. 이 지시서가 「판매팩과 견줘 보라」고 시켜서,
5번이 남의 몫을 들여다보고 「판매팩 28칸이 옛것」이라고 적었다.
**네 일은 손님이 «코드로 받는» 것까지다.**

### 5단계 — 오류는 고친다

검수공통 2절을 따른다. 코드를 고쳤으면 **3단계를 다시 돌려** 정말 고쳐졌는지 본다.

⚠ **`app/` 아래 화면 코드는 읽기만 한다**(검수공통 3절).
`lib/export/` · `lib/design-presets.ts` 는 **고쳐도 된다** — 손님이 받는 파일을 만드는 곳이다.

#### ⭐⭐ 흠이 나오면 «반드시 브라우저로 그 화면을 열어 본다» (2026-08-21)

**검사기가 짚었다고 팩이 아픈 것이 아니다.** 그날 첫 판 **120건 가운데 절반쯤이
검사기의 헛짚음**이었다. 열어 보지 않고 고치면 **잘 만든 자리를 망가뜨린다.**

| 검사기가 한 말 | 열어 보니 |
| --- | --- |
| 「align-items 를 안 줘서 늘어났습니다」 | `flex:1 1 0%` — 한 줄을 반씩 나눠 쓰라고 **일부러** 적어 둔 것 |
| 「덩어리가 0px 로 맞붙었습니다」 | 안여백 28px 이 있어 글은 28px 아래에서 시작 (40쪽 헛짚음) |
| 「썸네일 키가 607·118px 로 제각각」 | 상품 갤러리의 「큰 것 하나 + 작은 것 넷」 — 층이 다른 것 |
| 「탭이 제 화면을 가리킵니다」 | 지금 켜진 탭 — 제 모습 |

**고칠 것이 팩일 수도 있고 검사기일 수도 있다.** 검사기가 틀렸으면
`check-눈으로.mts` 를 고치고 **왜 틀렸는지 주석으로 남긴다.**
