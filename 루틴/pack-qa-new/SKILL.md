## 하는 일 — 검수공통 0절의 네 가지

팩 하나마다 아래를 **순서대로** 한다. 검수공통 1절의 차례를 그대로 따른다.

### 1. 기계가 먼저 (검수공통 1-1 · 1-2)

```bash
node _작업/팩검사.mjs <팩이름>
npx tsx check-presets.mts
npx tsx check-design.mts
npx tsx check-pack.mts
npx tsx check-사진.mts
npx tsx check-레이아웃.mts
npx tsx check-반응.mts <팩이름>
npx tsx check-눈으로.mts <팩이름>      # ⭐ 「사람처럼 보는 검수」 15항목 전부 (H묶음) + D6·G·F 까지 한 번에
```

**여기서 걸리는 것이 0 이 된 뒤에 눌러 본다.** 기계가 잡을 것을 손으로 찾지 않는다.

### 2. 사람처럼 눌러 본다 (검수공통 1-3)

새 팩이므로 **한두 화면만 보고 끝내지 않는다.**

| 무엇 | 얼마나 |
| --- | --- |
| **화면 목록** | 반드시. 여기가 출발점이다 |
| **묶음마다 대표 화면** | 묶음 수만큼 (보통 7~9개) |
| **흐름이 이어지는 곳** | 처음부터 끝까지 한 번 — 고르기 → 결제 → 완료, 또는 신청 → 확인 → 완료 |
| **빈 상태 · 오류 상태** | 걸러서 0건 만들기, 안 채우고 다음 누르기 |
| **관리자·운영자 화면** | 있으면 대표 화면 두엇 |

⭐ **흐름을 끝까지 한 번은 반드시 지난다.** 화면 하나만 보면 다 맞아 보인다.
앞에서 고른 값이 뒤로 안 넘어가는 것은 **두 화면을 이어서 봐야만** 드러난다.

### 3. 데이터가 화면끼리 맞는지 (검수공통 0절 ③)

- 앞 화면에서 고른 것(수량·옵션·할부·기간)이 뒤 화면에 그대로 오는가
- 같은 값이 여러 화면에 나오면 다 같은가
- 합계가 항목의 합과 맞는가
- N/M 과 「남은 것」이 맞는가
- 적어 둔 개수와 실제로 보이는 개수가 맞는가
- 날짜 옆의 말(「이번 주」·「D-3」)이 오늘 기준으로 맞는가

### 4. 나온 오류는 «그 자리에서» 고친다

검수공통 2절을 따른다. 특히:

- **숫자 하나를 고치면 딸린 값을 전부 따라간다**
- **한쪽 등급을 고쳤으면 다른 등급도 본다**
- **뿌리(`template-data-<업종>.ts` · `lib/design-presets.ts`)까지 올라간다**
- **공통 CSS·JS 를 고쳤으면 짜임이 다른 팩도 한 장 열어 본다**

고친 뒤에는 **1단계 검사기를 다시 돌리고, 고친 화면을 다시 눌러 본다.**

#### ⭐⭐ 흠이 나오면 «반드시 브라우저로 그 화면을 열어 본다» (2026-08-21)

**검사기가 짚었다고 팩이 아픈 것이 아니다.** 그날 첫 판 **120건 가운데 절반쯤이
검사기의 헛짚음**이었다. 열어 보지 않고 고치면 **잘 만든 자리를 망가뜨린다.**

| 검사기가 한 말 | 열어 보니 |
| --- | --- |
| 「align-items 를 안 줘서 늘어났습니다」 | `flex:1 1 0%` — 한 줄을 반씩 나눠 쓰라고 **일부러** 적어 둔 것 |
| 「덩어리가 0px 로 맞붙었습니다」 | 안여백 28px 이 있어 글은 28px 아래에서 시작 (40쪽 헛짚음) |
| 「썸네일 키가 607·118px 로 제각각」 | 상품 갤러리의 「큰 것 하나 + 작은 것 넷」 — 층이 다른 것 |
| 「탭이 제 화면을 가리킵니다」 | 지금 켜진 탭 — 제 모습 |

**고칠 것이 팩일 수도 있고 검사기일 수도 있다.** 검사기가 틀렸으면
`check-눈으로.mts` 를 고치고 **왜 틀렸는지 주석으로 남긴다.**

#### ⛔ 없는 CSS 변수를 쓰면 «그 줄이 통째로 버려진다» (2026-08-21)

팩이 두 세대라 같은 뜻의 값이 이름이 다르다.

| 뜻 | 새 팩 | 옛 팩 |
| --- | --- | --- |
| 섹션 사이 | `--sec-gap` | `--sp-sec` |
| 덩어리 사이 | `--sp-block` | (없음 → `--s4`) |

한쪽만 적었더니 옛 팩 다섯 벌에서 **아무 소리 없이** 안 먹었다.
CSS 는 없는 변수를 만나면 경고가 아니라 **그 줄을 버린다.**
반드시 겹쳐 쓴다 — `var(새, var(옛, 기본값))`.
