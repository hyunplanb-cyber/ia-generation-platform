## 2단계 — 돈부터 본다

`balance` 를 부른다.

⚠ **크레딧 값을 «기록»하는 것이 이 회차의 또 다른 몫이다.**
판매팩의 「예시 이미지」 계획이 그 값을 기다리며 멈춰 있다
(`판매팩_자동화_지시서.md` 의 「②-1 예시 이미지」).
**영상 먼저, 남으면 이미지 한 장을 뽑아 값을 잰다.** 영상이 더 급하다.
잰 값은 `기록.md` 에 «영상 한 편 / 이미지 한 장» 을 갈라서 적는다.

- **크레딧이 모자라면 아무것도 만들지 말고 거기서 멈춘다.**
- ⚠ **크레딧을 사지 않는다.** 요금제를 올리지 않는다. 결제는 사람이 한다.
  모자라면 「얼마가 모자라서 못 했다」를 보고에 적고 끝낸다.
- 지난 회차 `기록.md` 에 적힌 한 편당 값을 보고 **몇 편을 만들 수 있는지 먼저 셈한다.**
  첫 회차라 값을 모르면 **한 편만** 만들고 값을 잰다.

만든 뒤 **반드시 열어 보고** 아래를 눈으로 확인한다. 하나라도 틀리면 다시 뽑는다.

## 4단계 — 영상을 뽑는다

모델은 **Seedance 2.0**(`seedance_2_0`). 4–15초, 소리 나옴, 9:16 됨,
**참조 이미지로 얼굴을 고정**할 수 있다.

- `duration` = **15**
- `medias` 에 `얼굴기준.png` 를 **`image_references` 로 넣는다** ← 빠뜨리면 딴 고양이가 나온다
- 프롬프트는 캐릭터 시트의 ②·③ 을 그대로 쓴다

만들 대본은 `인터뷰_대본.md` 에서 **아직 「✅ 만듦」이 안 붙은 첫 줄**을 가져온다.
날짜로 고르지 않는다 — 같은 것을 두 번 만들지 않기 위해서다.

## 5단계 — 뽑은 영상을 «반드시 열어 본다»

**이 단계를 건너뛰지 마라.** 「만들었다」와 「제대로 나왔다」는 다른 말이다.
2026-08-10 에 사장님이 유튜브 썸네일로 그걸 겪으셨다.

```
ffmpeg -v error -i <영상> -vf "fps=1,scale=440:-1" -q:v 3 f_%02d.jpg
```

뽑은 장면들을 **눈으로 본다.** 아래를 확인한다.

- [ ] 3단계의 일곱 가지가 그대로인가 (특히 **삼색 좌우**)
- [ ] **핀마이크가 화면에 보이는가**
- [ ] **컷이 없는가** (장면이 갑자기 바뀌지 않는가)
- [ ] 손·발가락이 이상하게 나오지 않았는가
- [ ] 입이 말에 맞춰 움직이는가

**하나라도 틀리면 그 영상은 버리고 다시 뽑는다.** 크레딧이 모자라면 안 쓰고 멈춘다 —
**틀린 것을 내보내느니 안 내보내는 게 낫다.**

   ⚠ 목소리는 **여성**이다. 낮게 깔지 않는다. 무심하고 담백한 톤이다.
2. 자막을 얹는다. **`인터뷰_대본.md` 의 「자막은 «우리 것»을 쓴다」 표를 그대로 쓴다.**

   ⚠ `영상틀_916.html` 을 **쓰지 마라.** 그 틀은 영상을 가운데 구멍(388×690)에 끼운다.

3. 마지막 판을 붙인다 — `_작업/표지붙이기.mjs` 와 같은 방식.

## 10단계 — 보고

사장님께 짧게 알린다. **「했다」가 아니라 「무엇이 나왔고 무엇이 안 됐나」**를 적는다.

- 몇 편 만들었나, 크레딧을 얼마 썼고 얼마 남았나

- 못 한 것이 있으면 **왜 못 했는지** (크레딧 모자람 등)
