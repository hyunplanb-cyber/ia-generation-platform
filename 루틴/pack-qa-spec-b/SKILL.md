## ⭐ 두 갈래 검수 지시문이 스펙팩에 실렸는지 본다 (2026-08-21 사장님 지시)

검수는 **두 갈래**다. 어느 쪽이 바뀌든 **스펙팩에 실려야** 손님에게 간다.

| 갈래 | 무엇을 보나 | 스펙팩 어디에 |
|---|---|---|
| **① 사람처럼 보는 검수** | 레이아웃 6 · UX 2 · UI 7 = **15개** (그 밖에 D·G·E) | **7-0** · 7-1~**7-9** |
| **② 기계가 보는 검수** | 파일 · 값 · 문서끼리 앞뒤 = **27개** (A·B·C·F) | **7-0** · **7-9-2** |

```bash
# 스펙팩에 두 갈래가 다 실렸는지 — 한 줄로 확인한다
grep -c "검수는 «두 갈래»입니다" <팩>/07_AI빌드_스펙팩.md      # 1 이어야 한다
grep -c "기계가 보는 검수 — 파일만 보고 재기" <팩>/07_AI빌드_스펙팩.md  # 1 이어야 한다
```

⛔ **0 이 나오면 스펙팩이 묵은 것이다.** 코드를 고쳐도 «찍혀 있는 파일»은 안 바뀐다.
다시 찍어야 한다:

```bash
npx tsx build-template.mts <업종키>        # 2뎁스 → 스탠다드·디럭스
npx tsx build-template-deep.mts <업종키>   # 3뎁스 → 플러스·프리미엄
npx tsx package-template.mts <상품키> --zip
```

⚠ **zip 까지 다시 굽지 않으면 손님에게 안 간다** (검수항목 B9).

### ⭐⭐ 흠이 나오면 «반드시 브라우저로 그 화면을 열어 본다» (2026-08-21)

**검사기가 짚었다고 팩이 아픈 것이 아니다.** 그날 첫 판 **120건 가운데 절반쯤이
검사기의 헛짚음**이었다. 열어 보지 않고 고치면 **잘 만든 자리를 망가뜨린다.**

| 검사기가 한 말 | 열어 보니 |
| --- | --- |
| 「align-items 를 안 줘서 늘어났습니다」 | `flex:1 1 0%` — 한 줄을 반씩 나눠 쓰라고 **일부러** 적어 둔 것 |
| 「덩어리가 0px 로 맞붙었습니다」 | 안여백 28px 이 있어 글은 28px 아래에서 시작 (40쪽 헛짚음) |
| 「썸네일 키가 607·118px 로 제각각」 | 상품 갤러리의 「큰 것 하나 + 작은 것 넷」 — 층이 다른 것 |
| 「탭이 제 화면을 가리킵니다」 | 지금 켜진 탭 — 제 모습 |

**고칠 것이 팩일 수도 있고 검사기일 수도 있다.** 검사기가 틀렸으면
`check-눈으로.mts` 를 고치고 **왜 틀렸는지 주석으로 남긴다.**
