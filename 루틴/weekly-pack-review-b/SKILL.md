## 다시 못 박는다 — 이것만은 반드시

| | |
|---|---|
| **앞 절반을 건드리지 않는다** | A가 같은 시각에 그것을 보고 있다 |
| **`_만드는중/` 을 열지 않는다** | 만들다 만 팩이다. **세지도 말고 흠으로 적지도 마라.** 업종을 셀 때도 `_판매팩/` 에 실제로 있는 것만 센다 — 그래야 A 와 같은 수를 세고 몫이 안 어긋난다 |
| **`npm run pack` 을 돌리지 않는다** | 24팩을 통째로 다시 굽는다. 둘이 동시에 돌리면 깨진다 |
| **zip 을 굽지 않는다 · 구글 시트에 올리지 않는다** | 마무리 루틴 몫이다 |
| **`검수기록.csv` 를 직접 건드리지 않는다** | 합치는 것은 마무리 루틴이 한다 |
| **우리 사이트 코드를 건드리지 않는다** | 문제를 찾으면 고치지 말고 적는다 |
| **완성화면을 지우지 않는다** | 고치는 것만 된다 |
| **사진이 빠졌으면 다시 끼우되 zip 은 굽지 않는다** | `이미지-끼우기.mts` 는 돌려도 된다(빠진 재료 채우기다). 다만 CSV 에 「사진 다시 끼움」이라고 적고 끝낸다 — 지금 `check-zip` 을 돌리면 **옛 zip** 을 보고 통과시킨다 |
| **중간에 실패했으면 `.done` 을 만들지 않는다** | 그래야 마무리가 반쪽짜리를 올리지 않는다 |
