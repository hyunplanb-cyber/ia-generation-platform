## 왜 이 루틴이 따로 있나

A와 B가 새벽 1시에 **동시에** 돈다. 그래서 둘 다 하면 부딪히는 일이 있다 —
`npm run pack` 은 24팩을 통째로 다시 굽고, `검수기록.csv` 는 한 파일이고,
구글 시트는 둘이 올리면 두 개가 된다. **그 셋을 여기로 몰아 뒀다**(2026-08-11).

## 1단계 — 둘 다 끝났는지 본다

`검수/<오늘날짜>_A.done` 과 `_B.done` 이 있는지 본다.

- **둘 다 있으면** → 계속한다
- **하나만 있으면** → 있는 쪽만 합치고, **없는 쪽은 「끝나지 않았다」고 보고에 크게 적는다.**
  포장·zip 은 **하지 않는다** — 반쪽 재료로 팔 물건을 만들지 않는다
- **둘 다 없으면** → 아무것도 하지 말고 그렇게 보고한다

⚠ **없다고 결론짓기 전에 «엉뚱한 자리»부터 뒤진다 (2026-08-18).**
그날 A 는 검수를 멀쩡히 끝내 놓고 CSV·done 을 캡처 폴더
(`판매용_템플릿/_마케팅/검수/`)에 넣었다. 뿌리의 `검수/` 만 보고 「A 가 안 끝났다」로
판단해 포장을 멈췄고, 그날 고친 것이 손님에게 안 갈 뻔했다.

```bash
ls 검수/ 판매용_템플릿/_마케팅/검수/ 2>/dev/null | grep -E "_A\.(csv|done)|_B\.(csv|done)"
```

캡처 폴더에서 나오면 **뿌리로 옮긴 뒤 계속한다.** 그리고 보고에
「A(또는 B)가 파일을 엉뚱한 자리에 뒀다」를 적는다 — 지시문을 고쳐야 할 신호다.

## 2단계 — 합친다

`검수/<날짜>_A.csv` 와 `_B.csv` 를 읽어 **`검수기록.csv` 뒤에 덧붙인다.**

- 머리줄은 한 번만
- **기존 줄을 지우거나 고치지 않는다.** 쌓기만 한다
- 같은 줄이 두 번 들어가지 않게 확인한다(날짜+업종+항목번호+근거파일이 같으면 같은 줄)

## 3단계 — 재료가 통과했으면 포장한다

**A·B 의 CSV 에 `못고침` 이 하나라도 있으면 포장하지 않는다.** 그대로 보고하고 끝낸다.
「검사가 통과하지 못한 것은 절대 배포하지 않는다」가 절대 규칙이다.

통과했으면 순서대로:

```bash
npm run pack                          # 재료 다시 굽기 — ⚠ 이것은 zip 을 «안» 굽는다
npx tsx package-template.mts --zip    # ← zip 은 여기서 구워진다. 빠뜨리지 마라
npx tsx check-zip.mts                 # 손님이 받는 파일이 성한가 — FAIL 0 이어야 한다
npx tsc --noEmit                      # 타입
```

⚠ **`--zip` 을 빠뜨리면 검사가 «옛 zip» 을 보고 통과시킨다. 아주 조용히 그렇게 된다.**
2026-08-11 에 실제로 그랬다 — 그날 팩 넷을 고치고 `npm run pack` + `check-zip` 만 돌리고
「통과했습니다」라고 두 번 보고했는데, **zip 은 전날 것 그대로였다.** 고친 것이 하나도 안 들어갔다.

**구운 뒤 `ls -la packs/` 로 시각이 오늘인지 눈으로 본다.** 그것까지 해야 끝이다.

`check-zip` 에서 FAIL 이 나오면 **거기서 멈추고** 무엇이 나왔는지 보고한다.

### 예시 사진 (2026-08-11 추가)

A·B 의 CSV 에 **「사진 다시 끼움」**이 적힌 팩은 사진이 zip 에 들어가야 한다.
`check-zip` 의 **F1·F2·F3** 이 그것을 잰다 — 태그가 가리키는 webp 가 실제로 zip 에 있나,
`사진바꾸기.csv` 줄 수가 사진 수와 같나, 지도 자리에 사진이 들어갔나.

`npm run pack` 은 완성화면을 다시 «만들지» 않으므로 사진은 살아남는다.
다만 누가 `build/generate.mjs` 를 돌렸다면 통째로 날아간다 — 그때는
`check-zip` 이 「예시 사진 N장이 zip 에 없습니다」로 잡는다. 잡히면 배포하지 말고
`npx tsx 이미지-끼우기.mts <팩폴더>` 로 다시 끼운 뒤 **`--zip` 부터 다시** 한다.

### 스펙팩을 고쳤다면 — 재료부터 다시 굽는다 (2026-08-17 추가)

A·B 의 CSV 에 **「스펙팩 고침」**이 적혀 있으면 `template-data-<업종>.ts` 가 바뀐 것이다.
**그건 `npm run pack` 만으로는 4등급에 안 퍼진다.** 그 업종의 재료를 먼저 다시 굽는다.

```bash
npx tsx build-template.mts <업종키>        # 2뎁스(스탠다드·디럭스) 스펙팩
npx tsx build-template-deep.mts <업종키>   # 3뎁스(플러스·프리미엄) 스펙팩
npm run pack                              # 그다음에 평소 차례대로
npx tsx package-template.mts --zip
```

⚠ **`build-template.mts` 는 인자를 안 주면 LMS 를 굽는다.** 업종키를 반드시 준다.
⚠ 다 구운 뒤 **zip 안을 열어 고친 글이 실제로 들어갔는지 확인한다.** 스펙팩은 손님이
AI 에 넣는 파일이라, 여기서 빠지면 손님 화면이 옛 지시대로 만들어진다.

## 4단계 — 구글 시트로 올린다

⚠ **구글 드라이브는 「줄 추가」가 안 된다.** 고칠 도구가 아예 없다.
그래서 **`검수기록.csv` 전체(그때까지 누적분)를** 새 시트로 올린다.
사장님은 **맨 위 시트 하나만 열면 전부 보인다.**

- 제목: `판매팩 검수 <날짜>`
- `create_file` 에 `contentMimeType: text/csv` · `textContent` 로 CSV 를 넣으면 시트로 바뀐다
- ⚠ **올린 뒤 `read_file_content` 로 다시 읽어 줄 수를 센다.**
  「만들었다」는 응답만 믿지 마라 — 2026-08-11 에 `fileSize:1` 이 와서 확인해 보니
  내용은 멀쩡했다. 확인하지 않으면 빈 시트를 올려 놓고 됐다고 말하게 된다

⚠ **드라이브가 안 붙어 있을 수 있다.** 그러면 **실패로 치지 말고**
「올리지 못했습니다. 파일은 `검수기록.csv` 에 있습니다」라고 보고에 적는다.
CSV 는 드라이브와 상관없이 이미 2단계에서 써 두었다.

## 5단계 — 총괄 보고

사장님이 아침에 이것 하나만 보면 되게 쓴다.

- **구글 시트 주소** (못 올렸으면 그 사실과 CSV 경로)
- 이번 회차에 본 업종 전부 · **찾은 것 · 고친 것 · 못 고친 것** 건수
- **못 고친 것은 하나하나 「무엇이 · 어디에 · 왜 못 고쳤나」**
- **사람이 정해야 할 것** — A·B 가 `사람확인필요` 로 남긴 것
- A·B 중 안 끝난 것이 있으면 **그 사실을 맨 위에**
- 포장을 건너뛰었으면 **왜 건너뛰었는지**
- `검수항목.md` 에서 ⬜ 가 ✅ 로 바뀐 것이 있으면 무엇인지, 지금 ⬜ 가 몇 개 남았는지

### ⭐ 「루틴이 제 지시를 지켰나」도 같이 적는다 (2026-08-18 사장님 지시)

**팩만 검수하지 말고 «검수하는 우리 자신»도 같이 본다.**
2026-08-18 에 A 와 B 가 같은 밤에 «둘 다 지시문에 적혀 있는 것»을 어겼다 —
A 는 CSV·done 을 캡처 폴더에 넣었고(그래서 포장이 통째로 멈췄다),
B 는 고친 뒤 zip 을 다시 굽지 않았다(그래서 고친 것이 손님에게 안 갈 뻔했다).
둘 다 «지시문 뒷부분»에 적힌 것이다. 루틴이 길어질수록 뒤를 놓치는 것으로 보인다.

그래서 보고 맨 아래에 **한 문단**을 더 적는다.

- **이번 회차에 A·B 가 지시를 어긴 것이 있나** — 어겼으면 무엇을, 지시문 어디에
  적혀 있던 것인지. 없으면 「없음」이라고 한 줄
- **지난 회차에도 같은 것을 어겼나** — `검수기록.csv` 에서 지난 회차 줄을 훑어
  견준다. 두 회차 이어서 같은 것을 어겼으면 **「지시문을 고쳐야 한다」고 크게 적는다.**
  사람이 더 조심하는 것으로는 안 고쳐진다 — 지시문 자체가 잘못 적힌 것이다
- 어긴 것을 **`검수기록.csv` 에도 남긴다** — 업종 칸은 `(루틴)`, 항목번호는 `자기점검`.
  그래야 다음 회차가 이 줄을 보고 견줄 수 있다

> 이 문단이 «다음 회차가 견줄 자료»가 된다. 빼먹으면 다음 주에 볼 것이 없어진다.
