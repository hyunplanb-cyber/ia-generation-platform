### ② `main` 이 아니면 — **가지를 합치지 말고, 네 커밋만 골라 옮긴다**

⛔ **`git checkout` 으로 가지를 바꾸지 마라.** 그 가지에서 다른 일이 돌고 있다.
⛔ **`git merge` 로 통째로 합치지 마라.** 그 가지에는 **만드는 중인 업종**이 얹혀 있을 수 있다.
   2026-08-25 에 `pack/petcare-2026-08-24` 가 그랬다 — 통째로 합쳤다면 완성화면도 zip 도
   없는 반려동물케어가 **판매 목록에 네 등급 다 떠 버린다.** 손님이 사면 받을 것이 없다.

**딴 자리(worktree)를 하나 내서 거기서 옮긴다.** 지금 작업 폴더는 손대지 않는다.

```bash
git worktree add ../_qa-main main
git -C ../_qa-main cherry-pick <검수 넷과 네 커밋 번호들>   # 오래된 것부터
git -C ../_qa-main push origin main
git worktree remove ../_qa-main
```

- 옮길 커밋은 **A·B·NEW·userpack 이 CSV·보고에 적어 둔 번호**와 **네 커밋**뿐이다
- **만드는 중인 업종의 커밋은 절대 넣지 마라.** 검수가 안 본 것이니 네가 보낼 것도 아니다
- 부딪히면(conflict) **멈추고** `git -C ../_qa-main cherry-pick --abort` · `git worktree remove` 한 뒤
  보고에 「부딪혀서 못 옮겼습니다 — 커밋 <번호>」라고 적는다. 억지로 풀지 마라

  `BUILDING` 이면 몇 분 기다렸다 다시 본다. `ERROR` 면 **「배포가 깨졌습니다」로 보고**한다

### ⛔ 밖에서 zip «안»까지는 못 본다 — 그러니 봤다고 하지 마라

팩 다운로드(`/api/packages/<팩>/<등급>/download`)는 **로그인하고 산 사람만** 받는다.
루틴은 로그인이 없다. 그러니 **실서버 zip 을 열어 확인할 길이 없다.**

| 적어도 되는 말 | 적으면 안 되는 말 |
|---|---|
| 「밀었고 배포 READY 입니다 (커밋 `<번호>`)」 | 「실서버 zip 을 열어 확인했습니다」 |
| 「깃허브 main 이 `<번호>` 입니다」 | 「손님이 새 zip 을 받는 것을 봤습니다」 |

⚠ **모르는 것을 안다고 하지 않는다.** 확인 못 한 것은 「확인 못 함」이라고 적는다.

⚠ **막힌 것은 그대로 막혀 있다** — `npm publish` · `gh release` 는 네 일이 아니다.
   `vercel` 명령도 쓰지 마라. **깃허브에 밀면 Vercel 이 저절로 배포한다.**

# 5단계 — 구글 시트로 올린다

⚠ 구글 드라이브는 「줄 추가」가 안 된다. **`검수기록.csv` 전체를 새 시트로** 올린다.

- 제목: `판매팩 검수 <날짜>`
- `create_file` 에 `contentMimeType: text/csv` · `textContent` 로 CSV 를 넣으면 시트가 된다
- ⚠ **올린 뒤 `read_file_content` 로 다시 읽어 줄 수를 센다.** 「만들었다」는 응답만 믿지 마라
- 드라이브가 안 붙어 있으면 **실패로 치지 말고** 「올리지 못했습니다. 파일은 `검수기록.csv` 에 있습니다」라고 적는다

### ⭐ 루틴 백업이 갈라졌는지 본다 (2026-08-21)

루틴 파일은 저장소 «밖»(`~/.claude/scheduled-tasks/`)에 산다. git 에 안 올라가니
새 컴퓨터로 옮기면 따라오지 않는다. 그래서 `루틴/` 에 사본을 둔다.

```bash
npx tsx 루틴-백업.mts            # 다르면 어디가 다른지 보여 주고 1 로 끝난다
```

**1 로 끝나면** — 지난 한 주에 누군가 루틴을 고치고 사본을 안 남긴 것이다.
살아 있는 쪽이 맞으니 담고 커밋한다.

```bash
npx tsx 루틴-백업.mts --저장
git add 루틴 && git commit -m "루틴 백업 — <무엇이 바뀌었나>"
```

⚠ **되돌리기(`--되돌리기`)는 네가 하지 않는다.** 그건 새 컴퓨터에서 복구할 때만 쓴다.
⚠ `루틴/_시각표.json`(언제 도는지)은 **`--저장` 이 저절로 다시 만든다.** 손대지 않는다.
  시각·켜짐이 바뀌었으면 재기가 그것도 짚어 준다.
