# 루틴 백업

여기 있는 것은 **사본**이다. 진짜로 도는 것은 저장소 밖에 있다.

```
살아 있는 곳   C:\Users\glim0\.claude\scheduled-tasks\
사본(여기)     루틴/
```

루틴 파일은 git 에 안 올라가는 자리에 산다. 그래서 **새 컴퓨터로 옮기면 따라오지 않는다.**
2026-08-21 에 사장님 지시로 사본을 두기로 했다.

---

## 쓰는 법

```bash
npx tsx 루틴-백업.mts              # 재기만 한다 (기본) — 다르면 어디가 다른지 보여 주고 1 로 끝난다
npx tsx 루틴-백업.mts --저장        # 살아 있는 루틴 → 여기   (평소 백업)
npx tsx 루틴-백업.mts --되돌리기    # 여기 → 살아 있는 루틴   (새 컴퓨터에서 복구)
```

⛔ **말없이 갈라지는 백업은 없느니만 못하다.** 그래서 기본이 «아무것도 안 하고 재기»다.
루틴을 고쳤으면 `--저장` 을 같이 돌린다. 잊어도 다음 일요일 마무리 루틴이 잡아 준다.

### ⛔ 담기(`--저장`)에 막이 둘을 달아 두었다

2026-08-22 에 되돌리기를 시험하다 **백업하려다 백업을 지우는 자리**를 봤다.
새 컴퓨터에서는 살아 있는 쪽이 «비어» 있다. 그때 `--저장` 을 누르면
「살아 있는 쪽에서 다 지워졌구나」 하고 **사본 열둘을 통째로 지운다.**

| 언제 | 어떻게 막나 |
| --- | --- |
| 살아 있는 루틴이 **하나도 없을 때** | 담지 않고 멈춘다. 「새 컴퓨터라면 되돌리세요」라고 알려 준다 |
| 사본의 **절반 넘게 지우려 할 때** | 무엇이 지워지는지 이름을 다 보여 주고 멈춘다. 정말이면 `--정말지운다` 를 붙인다 |

## 되돌리기는 진짜 되나 — 2026-08-22 에 확인했다

말로만 「된다」고 하지 않았다. **네 가지로 망가뜨려 보고 되돌렸다.**

| 망가뜨린 것 | 되돌린 뒤 |
| --- | --- |
| 내용을 고쳐 놓기 | 한 자도 안 틀리고 돌아옴 |
| 폴더를 통째로 지우기 | 돌아옴 |
| 폴더는 두고 파일만 지우기 | 돌아옴 |
| 루틴 폴더를 **통째로 치우기**(새 컴퓨터인 척) | 열둘 다 돌아옴 |
| 사본에 없는 폴더를 만들어 두기 | **건드리지 않고 그대로 뒀다** |

지문(sha1)으로 견줘 **12/12 가 한 자도 안 틀렸다.** 되돌린 뒤 예약 아홉의 등록도
그대로 살아 있었고 다음 실행 시각도 멀쩡했다.

## ⚠ 파일만으로는 복구가 안 된다

`SKILL.md` 에는 **「언제 도는지」가 없다.** 되돌리기는 파일만 돌려놓는다.
등록 정보는 [`_시각표.json`](_시각표.json) 이 맡는다 — 되돌린 뒤
**그 파일을 보고 Claude 에게 등록을 시켜야** 진짜로 돈다.

### `_시각표.json` 은 «저절로» 갱신된다 — 손대지 않는다

`--저장` 을 돌릴 때마다 **예약 등록 원본에서 다시 만든다.** 손으로 고쳐 봐야 다음 번에
덮어쓴다. 원본은 세션 아이디 밑에 있어 자리가 바뀔 수 있으므로 **찾아서** 읽는다.

```
AppData/Roaming/Claude/claude-code-sessions/*/*/scheduled-tasks.json
```

**시각·켜짐·하는 일·승인 권한 수가 바뀌면 재기가 잡아낸다.**

```
≠ _시각표.json                  등록이 3군데 달라졌습니다
    ≠ pack-qa-dispatch — 시각이 바뀌었습니다: 화요일 00:25 → 금요일 03:00
    ≠ pack-qa-new — 꺼졌습니다
    － 없어진루틴 — 등록이 사라졌습니다
```

⚠ **마지막 실행 시각·만든 때는 담지 않는다.** 돌 때마다 바뀌어서 매주 헛경보가 난다.
⚠ **시각표는 `--되돌리기` 로 못 고친다.** 되돌리기는 SKILL.md 만 옮기고 등록은 안 건드린다.
  시각표는 살아 있는 등록에서 «만들어지는» 것이라 **언제나 살아 있는 쪽이 옳다.**
⚠ **승인해 둔 권한은 안 따라온다** — 이 컴퓨터의 경로라서다. 개수만 남긴다.
  새 컴퓨터에서는 루틴이 처음 돌 때 다시 승인해야 한다.

| 갈래 | 루틴 | 언제 |

| **판매팩 만들기** | `weekly-sales-pack` | 월 11:20 |
| **SNS** | `weekly-sns-content` | 월 11:00 |
| **검수 — 맏이** | `pack-qa-dispatch` | 일 00:25 분배 · 아침 마무리 |

### 등록 안 된 폴더 셋

`weekly-pack-review` · `weekly-pack-review-b` · `weekly-pack-review-finish` 는
폴더만 있고 **예약에 등록돼 있지 않다.** `pack-qa-*` 다섯이 그 자리를 물려받았다.
지우지 않고 두는 것은 옛 판단 근거가 적혀 있어서다 — **되돌릴 때 켜지 않는다.**
